OPTION 1: THE FULL-STACK ARCHITECT & SYSTEMS ENGINEER (RECOMMENDED)
--------------------------------------------------------------------------------
Most AI video clipping tools cost $50–$100/month, upload private media to third-party servers, and hit YouTube’s strict 10,000-unit API quota after just 4 to 5 uploads.

I wanted something faster, 100% private, self-hosted, and completely quota-free.

So I engineered PulseCut AI — a complete end-to-end studio that converts hours of raw podcasts, gameplay, and live streams into engaging 9:16 vertical Shorts, Reels, and TikToks.

Here is how the architecture works under the hood:

1. Local Speech-to-Text (Zero Cloud Cost):
Instead of paying per-minute transcription API fees or leaking client audio, I integrated on-device Sherpa-ONNX speech recognition (NVIDIA NeMo transducer). Audio never leaves the local machine, and transcription runs in near real-time.

2. Quota-Free YouTube Studio Browser Daemon:
YouTube’s Data API v3 charges 1,600 quota units per video upload, effectively capping automation at ~5 videos/day. To solve this, I designed a custom Playwright browser automation daemon. It maintains persistent session authentication, opens a local Chrome instance, and automates upload, metadata insertion, and scheduled publishing for 40–50+ Shorts daily with zero API limits.

3. Computer Vision & Automated 9:16 Reframing:
Using edge-detection and facial heuristics, the engine automatically detects webcam overlays in gaming streams, separates the player from gameplay, and generates clean split-screen vertical compositions.

4. Hardware-Accelerated Kinetic Subtitles:
Generates dynamic, word-level active subtitle animations and high-converting hooks rendered natively through FFmpeg and Pillow.

5. High-Throughput Async Backend:
FastAPI backend coupled with an adaptive fair-queue job scheduler that dynamically regulates CPU/RAM load, preventing machine lockups during heavy encoding tasks. The frontend is built with zero-dependency responsive JavaScript for instant load times and seamless state syncing.
